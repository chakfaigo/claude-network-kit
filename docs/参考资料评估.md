# 参考资料评估

资料初查：2026-10-31；Net.Coffee 11项内容已于2026-11-05再次核对。下述结论基于当时版本；安装时优先复核官方当前文档。本仓库不复制私人聊天、浏览器记录、供应商账号或本机审计原件。

## CCBaga

[仓库](https://github.com/liseami/CCBaga) · [中文说明](https://github.com/liseami/CCBaga/blob/main/README.zh-CN.md) · [Network Skill](https://github.com/liseami/CCBaga/blob/main/skills/ccbaga-network/SKILL.md)

第三方工具，功能包括 Claude 本地身份归档/切换、独立伴生浏览器、浏览器指纹、系统时区/语言/地区、CLI维护和独立网络部署。不是官方 Claude CLI 的运行依赖。

- 伴生浏览器指纹不等于 CLI 或官方桌面端指纹。
- 清理或切换身份会影响本地登录、设置、插件和历史；已经正常工作的环境无需因此清理。
- 系统时区/语言是全机设置，未发现运行官方 CLI 必须伪装它们的依据。
- 其网络 Skill 是另一整套服务器、代理和 TUN 方案，包含关闭系统代理的步骤；不能照搬到本包受管 TUN/PF 之上。
- 项目自己说明，本地设置不能修改服务端记录，不能保证匿名或账号可用；绿色核验也不等于独立 DNS/WebRTC 泄漏检查。

只做了材料核对，不是完整仓库安全审计。不要把“热门”理解成必须安装或安全保证。

## Net.Coffee

部署必须执行[11项强制配置与验收标准](NetCoffee强制配置与验收.md)，并阅读[实际排查经验](实际排查经验.md)。下面的资料评估不能替代逐项验收。

[Claude Code 稳定使用指南](https://ip.net.coffee/claude/claudecode.html)

| 建议 | 取舍 |
|---|---|
| 稳定出口、Claude规则优先、避免意外回落 | 有实际工程价值，需用日志和实际请求核验 |
| DNS、IPv6、UDP检查 | 有必要，但按实际架构处理，不是所有人都应全机禁用；本包已有相应限制 |
| 家宽变IP绝不触发风控 | 没有官方保证，不作为轮换出口的依据 |
| fingerprint:chrome 就与浏览器一样 | 不成立为通用结论；隧道外层与内层 TLS 不同，CLI 没有 Canvas/WebGL 浏览器指纹 |
| 单IP并发必须小于5 | 不是查证过的官方统一阈值，按套餐限额和实际错误判断 |
| DoH等于DNS一定走代理 | 加密与路由不同，仍须验证 detour/实际出口 |
| 固定十几个域名覆盖全部功能 | 功能、认证、更新、遥测和插件会变化；不要盲目全拦共享CDN |
| IP评分高就一定能用Claude | 评分是第三方算法，不等于官方资格、账号状态或无故障保证 |

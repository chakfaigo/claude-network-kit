# 安装与回退

## 准备

必须先读[Net.Coffee强制标准](NetCoffee强制配置与验收.md)，复制[验收模板](验收记录模板.md)到本地私有目录。中文语言可以保留；未测不能视为通过，安装成功不代表完成交付。

准备 Apple Silicon Mac（macOS 13+）、本机管理员权限、自己的 SOCKS5 家宽账号、供应商确认的固定出口 IPv4。代理主机 IP 不一定就是出口 IP，不要猜测。可选前置只支持本版本规定的美国 VMess/WS 线路；没有它也可直连家宽。

配置入口只向本地 `portable/private/node.json` 保存信息，目录权限 0700、文件 0600，不联网、不改系统、不覆盖已有配置。用户名密码隐藏输入。不要填 Claude 登录密码；填写的是代理供应商凭据。所有示例必须替换；示例文档地址故意不可用。

若有普通代理，复制 `upstream.example.json` 到仓库外的私有目录，替换自己的字段；配置入口会读取该文件。不要把真实上游配置提交到仓库。没有上游时留空：不会获得普通代理分流，Origin 下普通流量是直连。

## 安装过程

1. 普通用户双击配置入口，然后双击安装入口。不要用 sudo 启动整个程序。
2. 安装器检查架构、系统、已有保护、系统代理、默认路由、TUN 冲突及文件摘要。
3. 有上游时先检查其美国出口；接着验证家宽直连，失败才尝试上游前置。家宽出口必须符合预期。无上游时只检查直连。
4. 检查阶段最多启动临时本地监听，不修改系统代理、PF 或路由。失败即停。
5. 网络检查通过后，请求这台 Mac 的管理员授权。安装会备份本机配置，安装受管核心、PF、防护后台和菜单/提醒，修改相关系统代理/DNS/IPv6设置，并把 Claude Code 全局代理指向本机 10808。
6. 等待 Home 与日志检查通过，再开始应用验收。

通过远程桌面安装可能短暂断开远程会话，需有人在目标机旁处理授权与恢复。不应在现用机器上把首次安装器当升级器使用。

## 日常操作

- Home：受保护目标只经家宽。每次手动选择 Home 会按已实现逻辑检测可用的直连／前置路径。
- 家宽故障：受保护目标被阻断，后台检查恢复；不会直接让 Claude 改走普通代理。恢复要求连续两轮验证。
- Origin：受保护目标继续阻断；有上游时普通流量走上游，没有时普通流量直连。
- 菜单栏：查看 Home/Origin、原因、更新时间和事件；通知是否可见仍取决于 macOS 权限。
- 导出诊断：输出经过筛选的诊断，不输出节点密码、UUID或请求正文。分享前仍需人工确认设备信息。

## 回退和卸载不是一回事

Origin 是受保护的普通网络模式，不是卸载，不会撤销 PF、TUN 或全部系统设置。核心停机时其他应用可能也不能联网；UDP、IPv6 和部分局域网连接可能受限制。

安装会在这台电脑的 `/Library/Application Support/ClaudeResidential/private/before-guard` 等位置保存备份。恢复必须以该机实际备份和安装状态为依据。当前没有面向任意状态的一键卸载器；不要删后台文件、独立清空 PF、套用其他人的备份或随意运行网上卸载命令。需要彻底卸载时，先导出诊断，由维护者核对本机备份后逐项恢复。

安装中断也可能已建立部分保护。先保留日志，不要重复清空配置或强制联网。具体是否可重跑 Home，需看安装是否已完成发布；首次安装发现已有目录会拒绝覆盖。

## 本版本的完整性检查

`manifest.json` 对分发文件做 SHA-256 校验；可变的本地 `private/node.json` 不属于分发清单，由字段校验和实际出口检测把关。摘要清单是损坏检测，不是签名或发布者身份认证；应从本仓库 Release 下载并核对 Release 所附摘要。

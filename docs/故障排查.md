# 故障排查

按层次排查，避免为了联网撤销保护。

| 现象 | 先看什么 | 不应据此做什么 |
|---|---|---|
| 配置入口失败 | 字段格式、固定公网IPv4、已有private/node.json、上游协议 | 不要把个人密码发到Issue，也不要改成随机预期IP |
| 首次安装被拒绝 | 现有VPN/TUN/代理、已有保护目录、macOS/架构 | 不要强行删已有服务或备份 |
| 普通代理检查失败 | 是否VMess/WS、美国出口、端口、供应商状态 | 不跳过上游检查来安装未知线路 |
| 家宽直连失败、前置成功 | 电脑到家宽链路，前置路由记录 | 不认定家宽出口本身速度必然更快 |
| 两条家宽路径都失败 | 供应商、认证、出口变更、维修 | 不给Claude添加普通代理直出兜底 |
| Home被禁用 | 菜单原因、最新状态时间、导出诊断 | 不反复换IP或关闭PF |
| CLI找不到 | 独立安装及PATH | 不把VS Code内置二进制随意移走 |
| CLI可用桌面不可用 | 应用自身代理、Chat/Code/远程差异 | 不凭终端变量认定桌面已覆盖 |
| 403/429 | HTTP上下文、登录、权限、限额、服务状态 | 不一律归因IP，也不使用多出口规避限额 |
| 输出慢或断流 | 首字、重试、长连接、丢包、模型负载 | 不只看下载测速 |
| 重启/开盖后不可用 | 守护服务、路由、状态是否新鲜 | 不将旧的健康状态当作当前验证 |

日志入口：用户目录 `~/Library/Application Support/HomeGuard/logs`；菜单状态变化日志；管理员导出的诊断。后台详细记录是私有数据，默认不上传。先记录问题时间、客户端版本、模式、错误码，再检查对应层。安装过程中断网时保留终端窗口信息。

地区/IP评分问题应分开判断：公开查询站点与目标服务可能用不同数据库；网页“地区受限”也可能涉及账号或开放资格。没有依据时不改网络。

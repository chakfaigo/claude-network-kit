# 新机快速接入

适用：Apple Silicon、macOS 13+、首次安装。版本见包内`portable/VERSION`。已有安装请转到[更新与维护](更新与维护.md)，不要重跑首次安装。按本页推进，再用[强制流程](必须执行的部署流程.md)留证据；不用从历史会话找脚本。

目标是一次查清冲突、一次配置、按阶段验证。配置步骤可以更快，实际故障和业务验收不能用别人的结果代替。中文可保留；不要求改语言、时区或浏览器身份。

## 1．下载完整包，先做只读检查

从[最新Release](https://github.com/chakfaigo/claude-network-kit/releases/latest)下载ZIP与`SHA256SUMS.txt`，在两者所在目录运行`shasum -a 256 -c SHA256SUMS.txt`，结果应为OK，然后完整解压。不要分发已经填写过线路的文件夹。

双击`portable/接入检查.command`。它使用随包Python，不需要先装Homebrew、系统Python或开发工具；不请求管理员、不联网、不改代理/PF/TUN、不读线路凭据。包内完整性、平台、安装阶段、系统代理、TUN存在性、CLI默认配置等会分别报告：

| 结果 | 怎么做 |
|---|---|
| 符合所查基线 | 仅表示这一项所查内容符合，不等于整机通过 |
| 需要处理 | 看具体原因；包损坏、平台不支持、已有网络接管、安装版本不一致不能硬装 |
| 待核验 | 需要人工/实际客户端证据；新机未安装时没有Home状态、菜单或CLI设置是正常的阶段性缺项 |

脚本读取不到时不会标通过。它也不能发现所有VPN、扩展、登录项或项目设置。首次安装前仍须确认其他网络控制者、管理员维护条件及本机恢复手段。

需要保存结果时，在完整包目录用随包Python运行：

```sh
./portable/python/bin/python3.12 -I -B ./portable/src/check_setup.py --json --output ./接入检查.json
```

只创建新的0600文件，不覆盖旧记录；仍应保留在本地。退出码0表示没有发现“需要处理”的所查项目，不表示所有待核验项通过；2表示发现需处理项。

## 2．填自己的线路，然后安装一次

双击`portable/配置线路.command`：填写自己的SOCKS5家宽账号和供应商确认的固定公网IPv4。不是Claude密码。可选普通代理按示例准备本地文件；没有上游就留空。不可把网关解析IP当成最终出口。

双击`portable/安装.command`。程序先做线路预检，再在**终端通过sudo请求本机管理员密码**；输入不回显是正常行为。不要sudo启动整个入口。不要因没有弹出图形密码窗口而重装，也不要并行点Home/Origin。

安装器负责TUN/PF、DNS/IPv6、CLI全局代理和菜单/提醒登记。系统HTTP/HTTPS/SOCKS/PAC/自动发现保持关闭；国内分流已内置，不用再建第二套Clash/PAC规则。

无上游生成3份生产配置；有上游生成5份。待Home达到本次新鲜状态、入口完整成功，再进入下一步。失败时先看本次日志和当前模式，不能假定自动回滚。详见[安装说明](安装与回退.md)。

## 3．配置Chrome，分别检查实际客户端

按[Chrome专项](Chrome专用配置与验收.md)部署随包的三策略描述文件，或者由已有MDM统一设置。完全退出并重开日常Chrome，在`chrome://policy`检查三项实际值和状态。**描述文件没有语言、时区、账号、证书或代理服务器设置。** 安装网络包不会自动安装它。

CLI、VS Code和桌面端按[客户端验收](Claude客户端与验收.md)分别核对：全局文件、实际启动环境、项目/托管配置、认证目标及权限。远端执行/虚拟机/MCP不能默认继承本机结果。不要重复安装已有的正常客户端，也不要为了“验收”提前替用户登录。

## 4．复查配置，完成网络与稳定性验收

再次运行接入检查，确认新增的配置结果；已经安装的控制器/生成器应与包内源一致。它只给检查线索，活动PF、真实路由、Chrome实际政策页、故障恢复和通知到达必须另验。

按[稳定性验收与排障](稳定性验收与排障.md)记录实际客户端表现、分流、断流和恢复。登录前检查与用户自行登录后的业务验收分开。任何未验收功能仍留待验收，不用IP网页分数或健康绿色状态代替。

## 5．交接，再开始日常使用

按[验收模板](验收记录模板.md)填版本、适用客户端、证据、未决项与维护人；全部适用强制项完成后才能签收。日常只在需要时切Home/Origin，不把重复点Home当成加速或修复方法。Origin继续保护并阻断Claude，不是卸载。

| 常见停靠点 | 正确处理 |
|---|---|
| 已有安装/源版本不同 | 进入旧机维护流程，不能覆盖安装或只换解压目录 |
| 预检失败 | 保留错误码，按线路/出口/DNS逐层定位，不取消出口核验 |
| 网络已切换但菜单/提醒失败 | 核对实际模式和登记日志；修复用户服务，不先破坏网络保护 |
| Chrome政策未加载 | 检查安装作用域、冲突及是否完全重开，不反复重装网络 |
| Home间歇阻断 | 记录探测与恢复时段，查链路；不随机切出口、解除PF或放宽阈值 |

本版对用户服务重新加载完整配置，等待卸载、限制登记重试，并分别记录菜单/提醒与CLI结果；会短暂重启菜单/提醒，不因此额外重启网络核心。它修复了入口竞争问题，但不能保证上游链路永不抖动。

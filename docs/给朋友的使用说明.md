# 给朋友的使用说明

版本：v2026.11.18.1 · 2026-11-18

这是一个自带运行时、带菜单栏状态的 Mac 网络配置工具包。适合已有固定出口家宽线路、希望统一管理网络分流与 Claude 故障保护的人。**软件不提供代理线路或 Claude 账号。先判断是否适用，再决定是否安装。**

## 它能做什么

| 项目 | 本版行为 |
|---|---|
| Home 国内访问 | 未命中保护、固定家宽名单和协议限制的国内目标按规则直连 |
| Home 国外访问 | 允许的海外业务默认经自己的家宽；OpenAI、ChatGPT、Notion和列明的VS Code服务固定到家宽 |
| 可选前置代理 | Home中仅用来连接同一家宽，最终出口仍是家宽；多一跳不保证更快 |
| Claude故障保护 | 出口核验失败时拒绝受保护目标，恢复需重新验证；不自动让Claude改用直连或普通代理 |
| 状态与排查 | 菜单显示模式、原因与更新时间；提供通知、只读接入检查及诊断入口 |
| 系统设置 | 网络安装器接管TUN/PF、DNS/IPv6，并合并Claude Code全局代理设置；Chrome三项策略需另外安装和核验 |

Home阻断时，其他服务仍指向家宽，没有备用普通出口；它们未全部纳入Claude的拒绝名单，不能说“所有国外请求都逐次核验出口”。国内规则是本地快照，不代表所有国内地址均已覆盖。

## 是否适合你

需要同时具备：Apple Silicon Mac（M系列）、macOS 13或以上、本机管理员权限、自己可用的SOCKS5用户名密码线路，以及供应商确认的固定公网IPv4出口。Intel Mac、Windows、Linux不能使用这个安装包。

这是**首次安装包**。已有本工具、VPN/TUN、系统代理或企业网络策略时，先由维护者核对兼容和恢复方案，不能删除旧配置后强装。当前可选前置仅支持指定的美国出口VMess/WebSocket格式；普通订阅链接、其他协议不能直接填进去。

如果你只是想关闭Mac定位权限，用系统自带“隐私与安全性 → 定位服务”即可，没有必要为此安装整套网络工具。

## 下载与只读评估

1. 打开[本版发布页](https://github.com/chakfaigo/claude-network-kit/releases/tag/v2026.11.18.1)，下载 `claude-network-kit-macos-arm64.zip` 和 `SHA256SUMS.txt`。不用GitHub登录，也不需要Apple账号或AirDrop。
2. 将两个文件放在同一文件夹，在终端进入该文件夹，运行 `shasum -a 256 -c SHA256SUMS.txt`，应显示OK。摘要检查用于发现损坏，不能代替核对下载来源。
3. 完整解压。先读本文和[新机快速接入](新机快速接入.md)，再双击 `portable/接入检查.command`。这个入口只读、不联网、不读线路凭据、不改网络；可以先用它评估是否适合。
4. “待核验”不是通过，“发现冲突”不是提示你删除冲突软件。分享者的测试不能替代你这台Mac的验收。

## 决定安装以后

正式操作按[必须执行的部署流程](必须执行的部署流程.md)完成；下面是导航，不替代其中的检查。

1. 保存工作，准备有人在电脑旁处理认证和恢复的维护窗口。安装可能短暂断网；不要只靠远程桌面操作。
2. 双击 `portable/配置线路.command`，填自己的家宽服务器、端口、用户名、密码和最终出口IP；这不是Claude登录信息。没有可选前置时留空。
3. 普通用户双击 `portable/安装.command` 一次。程序先检测线路，通过后在终端请求这台Mac的管理员密码，输入不回显。不要用sudo启动整个入口，也不要同时点击Home/Origin。
4. 等本次安装结束、Home新状态验证通过，并核对菜单、日志和备份。报错可能意味着部分步骤已经执行，先停下排查，不要重复安装。
5. Chrome按[专项说明](Chrome专用配置与验收.md)部署 `portable/examples/Chrome网络基线.mobileconfig`，完全退出再重开，核对三项策略：`QuicAllowed=false`、`DnsOverHttpsMode=off`、`WebRtcIPHandling=disable_non_proxied_udp`。描述文件只包含网络策略，安装网络包不会自动安装它。
6. 公开包依靠TUN，**系统HTTP/HTTPS/SOCKS/PAC代理保持关闭**。不要照其他电脑的旧说明将系统代理手工设为10808；Claude Code的应用代理入口是另一层设置。
7. 用实际要用的Chrome、VS Code、CLI或桌面端分别验收；不使用的客户端可明确排除，以后启用再补验。完成国内直连、家宽出口、DNS、故障与恢复、重启/唤醒检查，填写[验收记录](验收记录模板.md)后再用于日常任务。

若macOS阻止运行，先核对来源、完整性及系统提示，由使用者按官方方式处理。本包没有Apple开发者公证，不要关闭Gatekeeper、SIP或安装未知“解锁脚本”。

## 日常怎么用、有什么影响

- **Home**：日常家宽模式。看新鲜状态，不反复点击Home来“加速”。
- **Origin**：Claude等受保护目标继续拒绝；有前置时普通海外业务走前置，无前置时普通业务直连。它不是卸载或完全撤销保护。
- **故障**：保存发生时间、当前状态和错误，暂停受影响任务；必要时运行 `导出诊断.command`。诊断需要管理员权限，分享前仍要检查是否包含IP、设备信息等。
- **网络影响**：海外访问集中占用家宽带宽；家宽不稳定会影响更多应用。严格UDP/IPv6/PF限制可能影响语音、游戏、AirDrop、打印和投屏。核心停机也可能导致普通应用断网。
- **恢复和卸载**：本版没有适用所有状态的一键卸载器。需维护者根据这台Mac的安装前备份恢复，不能使用别人的备份或直接清空PF。无法接受这一维护要求时，先不要安装。

## 能保证什么、不能保证什么

本版经过隔离逻辑测试和禁网的核心配置检查；它们验证程序规则，不验证你的线路、真实业务或整台机器的稳定性。详见[本版测试记录](版本验证-v2026.11.18.1.json)。当前保留3秒连接、5秒请求时限及两轮恢复；链路抖动可能触发阻断，阻断/恢复会重启核心并中断已有连接。没有宣称解决服务商故障或永不断线。

安装器不改变语言、时区或定位权限。IP评分、美国出口、拒绝定位都不能证明服务商无法判断实际所在地，也不改变服务使用资格。使用前核对[Anthropic支持地区政策](https://www.anthropic.com/supported-countries)及账号条款；本工具不承诺绕过地区限制或避免账号限制。

## 怎么安全地发给别人

只转发原始发布ZIP、发布页和这份说明。包里没有分享者的线路、账号、密码、浏览器资料或私人日志；每个人填写自己的信息。填写以后产生的 `portable/private/node.json`、真实上游JSON和本机备份只留本机，**不要把配置完成的整个目录重新打包给下一位朋友**。

需要协助时，提供版本、Mac芯片/系统版本、执行到哪一步、脱敏错误和大致时间即可。密码、Key、订阅身份、Cookie和原始诊断不要发进公开聊天或GitHub Issue。

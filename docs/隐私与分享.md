# 隐私与分享

此仓库和 Release 仅含程序、虚构示例、许可证、来源和通用说明。没有真实家宽节点、用户名、密码、订阅UUID、Claude登录态、浏览器资料、个人备份或私人聊天原文。

每位同事自己配置线路。private/node.json只在目标机生成；其内容不属于分发清单，并被.gitignore排除。Git忽略规则不是绝对保护：不要强制添加、复制到Issue、提交真实上游JSON或把已填写的整个安装目录重新打包上传。

分享时优先转发原始Release下载链接。若打包自己的副本，必须删除private和本机诊断/备份，并重新检查归档内容。私有GitHub仓库也不是凭据保险箱。

配置输入不通过网络上传；密码隐藏输入且不进入命令参数。实际安装和健康检测会连接你自己的代理及公开出口检测服务，这是核对线路所必需。不会用其他人的账号作为默认值。

不在仓库共享本机诊断原件。问题报告只包含必要错误码和版本；节点地址、出口IP、设备路径及账号标识按需要进一步脱敏。

仓库现已公开，任何人均可直接下载原始 Release，无需 GitHub 登录或协作者权限。公开内容仅包含通用程序和虚构示例；真实账号仍须在自己的电脑上填写，禁止提交到本仓库。
